# What the open-source CIM designs contributed

The design question was how to build and test a writable, charge-domain binary dot product on SKY130 with digital-only harness access. The following four repositories answer different parts of that question. Links identify the inspected revisions. All circuit, control and test code in this project was written for this macro. No upstream netlists, layouts or third-party figures are redistributed.

## Design decisions specific to this macro

A shared reference node feeding four comparator gates would present a different load from a signal node feeding one gate. Here each column has its own reference replica, and only the digital threshold code is shared. Signal and reference banks have equal numbers of full and quarter branches and identical bus-reset switches. This is our design choice based on the loading problem.

The array uses static latches with a buffered read path. A host can rewrite all weights and verify the stored state digitally. The analog sum is formed on local capacitors. An off-chip converter, fixed ROM weights, resistive memory programming and an embedded CPU would each change the circuit or its harness requirements; the prototype uses the previously proposed pads and commands.

The simulations also changed the implementation. The first single-column circuit missed several nominal quarter-threshold comparisons and fell below the directed midpoint margin target in hot, slow-clock operation. Increasing the unit capacitance, changing switch geometry, balancing comparator load and slowing regeneration improved the directed cases. The test record gives the evidence for the delivered revision. Schematic simulations address electrical behavior. Layout and measured silicon are later milestones.
